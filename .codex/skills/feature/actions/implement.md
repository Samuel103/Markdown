# Implement

Use these instructions when the user invokes `/feature implement` to build the feature documented in `context/current-context.md`.

1. Read repository instructions and their required context. Confirm `current-context.md` has actionable goals and an approved plan when applicable; ask about material gaps.
2. Implement only that feature, preserving unrelated work and conventions.
3. Run proportionate checks and report failures or unavailable checks.
4. Summarize, incorporate focused feedback, and validate meaningful revisions.

`current-context.md` is the source of truth; edit it only when asked.
