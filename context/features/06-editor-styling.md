# Feature — Editor Styling

## Goal

Améliorer la lisibilité et l'ergonomie de CodeMirror.

## Tasks

- Utiliser une police monospace.
- Ajouter un padding raisonnable.
- Ajuster la taille de police.
- Supprimer les bordures inutiles.
- Ajouter une séparation claire avec la preview.
- Préparer le support light/dark.
- Vérifier le focus clavier.

## Acceptance Criteria

- [x] L'éditeur est lisible.
- [x] Le focus est visible.
- [x] Le texte n'est pas collé aux bords.
- [x] Le layout ne bouge pas pendant la saisie.
- [x] Le composant est prêt à recevoir un thème.
