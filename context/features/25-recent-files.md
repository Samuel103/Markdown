# Feature — Recent Files

## Goal

Afficher les fichiers récemment ouverts.

## Tasks

- Enregistrer les derniers paths.
- Limiter le nombre d'entrées.
- Supprimer les doublons.
- Mettre le plus récent en premier.
- Permettre de rouvrir un fichier.
- Retirer une entrée invalide si le fichier n'existe plus.

## Acceptance Criteria

- [ ] Les fichiers récents sont persistés.
- [ ] Les doublons ne sont pas affichés.
- [ ] Un fichier peut être rouvert depuis la liste.
- [ ] Les paths invalides sont gérés proprement.
