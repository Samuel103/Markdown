# Feature — Project Setup

## Goal

Créer la base du projet React avec TypeScript et Vite.

## Tasks

- Créer le projet avec Vite.
- Utiliser React.
- Activer TypeScript.
- Installer les dépendances.
- Vérifier que le projet compile.
- Vérifier que `npm run dev` fonctionne.
- Supprimer les assets de démonstration inutiles.

## Commands

```bash
npm create vite@latest markdown-editor
cd markdown-editor
npm install
npm run dev
```

## Acceptance Criteria

- [ ] Le projet démarre sans erreur.
- [ ] React fonctionne.
- [ ] TypeScript fonctionne.
- [ ] Vite est utilisé.
- [ ] Aucun contenu de démonstration Vite inutile ne reste.

## Depends On

Aucune dépendance.
