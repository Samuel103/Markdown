# Markdown Editor — Feature Roadmap

## Objective

Ce dossier contient le roadmap du projet découpé par feature.

Chaque fichier représente une unité de travail suffisamment petite pour être implémentée indépendamment par un développeur ou un agent de code.

Les features `22` à `26` correspondent à la version desktop avec Tauri.
