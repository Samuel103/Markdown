# Feature — Preview Styling

## Goal

Rendre la preview agréable et proche d'un document Markdown classique.

## Tasks

Styliser :

- `h1`
- `h2`
- `h3`
- `p`
- `ul`
- `ol`
- `blockquote`
- `code`
- `pre`
- `table`
- `a`
- `hr`

Ajouter :

- padding;
- largeur de lecture confortable;
- scroll indépendant;
- styles de code inline et block.

## Acceptance Criteria

- [ ] Les titres ont une hiérarchie visuelle claire.
- [ ] Les blocs de code sont faciles à distinguer.
- [ ] Les tableaux sont lisibles.
- [ ] Les liens sont visibles.
- [ ] La preview possède son propre scroll.
