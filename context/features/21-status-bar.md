# Feature — Status Bar

## Goal

Afficher des informations simples sur le document.

## Suggested Information

- Nombre de mots.
- Nombre de caractères.
- Type du document : Markdown.

## Tasks

- Créer `StatusBar`.
- Calculer le nombre de caractères.
- Calculer le nombre de mots.
- Mettre à jour les valeurs en temps réel.
- Garder le calcul simple.

## Acceptance Criteria

- [ ] Le nombre de caractères est correct.
- [ ] Le nombre de mots se met à jour.
- [ ] La status bar n'occupe pas trop d'espace.
- [ ] Les calculs n'impactent pas la saisie.
